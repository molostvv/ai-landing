# Лендинг «ИИ-агенты для повседневных задач»

Одностраничный сайт, который объясняет, какие рутинные задачи можно поручить ИИ-агенту, и ведёт к заявке на бесплатную консультацию.

Стек: HTML, CSS и JavaScript без фреймворков и сборщиков, обработчик формы на PHP 8.3.

## Файлы

```
index.html            страница целиком (8 блоков)
assets/css/style.css  стили, mobile-first, все цвета — переменные в :root
assets/js/main.js     меню, плавная прокрутка, анимации, отправка формы, Яндекс Метрика
assets/img/           SVG-иконки и иллюстрации, favicon.svg, og-image.png (превью для соцсетей)
send.php              приём заявки → e-mail и Telegram; GET ?action=config отдаёт странице ID Метрики
config.example.php    образец настроек: EMAIL_TO, TG_BOT_TOKEN, TG_CHAT_ID, METRIKA_ID
privacy.html          политика конфиденциальности (шаблон по 152-ФЗ)
robots.txt, sitemap.xml
.htaccess             правила для Apache (закрыть config.php и README.md, сжатие, кэш)
```

## Установка на сервер

Нужен веб-сервер (Nginx или Apache) и PHP 8.1+ (проверено на 8.3) с расширением mbstring; для Telegram — curl или `allow_url_fopen`.

1. Скопируйте содержимое папки в корень сайта.
2. Скопируйте `config.example.php` в `config.php` и впишите настройки. Нужен хотя бы один канал доставки:
   - **Telegram** (рекомендуется): создайте бота через @BotFather, вставьте токен в `TG_BOT_TOKEN`, напишите боту любое сообщение и возьмите ID чата из `https://api.telegram.org/bot<токен>/getUpdates` → `TG_CHAT_ID`;
   - **E-mail**: адрес в `EMAIL_TO`. Работает через `mail()`, поэтому на сервере должен быть настроен почтовый агент (postfix/sendmail), иначе письма не уйдут.
   - `METRIKA_ID` — номер счётчика Яндекс Метрики (на тестовом сервере задан 113217396). Цели в счётчике создайте типа «JavaScript-событие» с идентификаторами `click_cta`, `form_submit`, `click_telegram`.
     Счётчик подключается кодом из кабинета Метрики (`main.js` → `loadMetrika`): Вебвизор, карта кликов, электронная коммерция (`dataLayer`), точный показатель отказов, внешние ссылки. Чтобы Вебвизор не записывал имя, телефон и текст заявки, у полей формы стоит класс `ym-disable-keys`.
     Метрика загружается отложенно — при первом действии посетителя (прокрутка, касание, движение мыши, клавиша) или через 3 секунды после загрузки страницы; цели, случившиеся раньше, копятся в очереди и отправляются сразу после загрузки счётчика. Без этого скрипты Метрики с Вебвизором (≈100 КБ) блокируют страницу на ~0,7 с и Lighthouse Performance падает с 95 до 77. Цена: не засчитываются визиты, которые закрыли страницу быстрее 3 секунд, ни разу её не тронув. Чтобы грузить сразу, в `initMetrika()` замените оба вызова `setTimeout(start, 3000)` на `start()`.
3. Замените плейсхолдеры `{{...}}` во всех файлах (список ниже) и в `robots.txt` раскомментируйте строку `Sitemap`.
4. Закройте служебные файлы от скачивания. Для Apache это уже делает `.htaccess`. Для Nginx:

```nginx
server {
    listen 80;
    server_name example.ru;
    root /var/www/landing/public;
    index index.html;
    charset utf-8;

    location ~ ^/(config\.php|config\.example\.php|README\.md)$ { return 404; }
    location ~ /\. { return 404; }
    location / { try_files $uri $uri/ =404; }
    location ~* \.(css|js|svg|png|ico)$ { expires 7d; try_files $uri =404; }

    # PHP выполняется только для обработчика формы
    location = /send.php {
        fastcgi_pass unix:/run/php-fpm/www.sock;
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    }
    location ~ \.php$ { return 404; }
}
```

5. Подключите HTTPS (например, Let's Encrypt) — без него браузеры помечают форму с личными данными как небезопасную.
6. Проверьте форму: отправьте тестовую заявку и убедитесь, что она пришла в Telegram или на почту.

Если за сайтом стоит прокси или CDN, `send.php` видит IP прокси, и лимит «5 заявок в час» будет общим для всех посетителей. В этом случае замените `REMOTE_ADDR` в `send.php` на заголовок с реальным IP, который выставляет ваш прокси.

## Плейсхолдеры

Контакты, реквизиты и цены на сайте не выдуманы: вместо них стоят плейсхолдеры. Замените их все перед публикацией.

| Плейсхолдер | Что вписать | Где встречается |
|---|---|---|
| `{{COMPANY_NAME}}` | Название компании или бренда | index.html (логотип, подвал, og:site_name), privacy.html |
| `{{PHONE}}` | Телефон, например +7 900 000-00-00 | index.html (подвал) |
| `{{EMAIL}}` | E-mail для связи и обращений по персональным данным | index.html (подвал), privacy.html, config.example.php (EMAIL_TO) |
| `{{TELEGRAM}}` | Ник в Telegram без @ | index.html (ссылки «Напишите нам в Telegram», подвал) |
| `{{SITE_URL}}` | Адрес сайта без слэша на конце, https://example.ru | index.html (og:url, og:image), privacy.html, robots.txt, sitemap.xml |
| `{{TG_BOT_TOKEN}}` | Токен Telegram-бота | config.php |
| `{{TG_CHAT_ID}}` | ID чата для заявок | config.php |
| `{{METRIKA_ID}}` | Номер счётчика Яндекс Метрики | config.php |
| `{{INN}}`, `{{OGRN}}` | Реквизиты оператора персональных данных | privacy.html |
| `{{LEGAL_ADDRESS}}` | Юридический адрес | privacy.html |
| `{{PRIVACY_DATE}}` | Дата редакции политики | privacy.html |
| `{{RETENTION_PERIOD}}` | Максимальный срок хранения заявок, например «3 лет» | privacy.html |
| `{{CROSS_BORDER_NOTE}}` | Текст о трансграничной передаче: Telegram — иностранный сервис, о такой передаче нужно уведомить Роскомнадзор. Согласуйте формулировку с юристом | privacy.html |

Ссылки на телефон, почту и Telegram хранят адрес в атрибуте `data-href`. Пока в нём плейсхолдер, ссылка ведёт к форме заявки; после замены `main.js` сам превращает её в рабочую ссылку `tel:`, `mailto:` или `https://t.me/...`. Так страница проходит валидатор W3C и до замены плейсхолдеров.

Шаблон политики конфиденциальности — отправная точка, а не юридическая консультация: перед публикацией покажите его юристу.

## Тексты

Тон — простой и дружелюбный, без жаргона. Все цифры экономии времени — примерные.

### Шапка (липкое меню)

Логотип {{COMPANY_NAME}} · Задачи · Как это работает · Вопросы · кнопка «Получить консультацию».

### 1. Первый экран

- Плашка: Первая консультация — бесплатно
- **H1:** Отдайте рутину ИИ-агенту — освободите до 10 часов в неделю
- Подзаголовок: Настроим цифрового помощника, который разбирает почту, записывает клиентов и готовит отчёты. Вы решаете, что важно, — он делает остальное.
- Кнопки: «Получить консультацию», «Как это работает»
- Под кнопками: Без технических знаний · Важные действия — только с вашего согласия · Первая консультация бесплатно
- Иллюстрация: схема «задача → ИИ-агент → результат», человек проверяет результат.

### 2. Что такое ИИ-агент

**H2:** Что такое ИИ-агент

ИИ-агент — это цифровой помощник, который не просто отвечает на вопросы, а сам выполняет задачи: разбирает письма, заполняет таблицы, записывает клиентов. Вы один раз объясняете, что и как делать, а агент повторяет это каждый день. Решения по-прежнему принимаете вы.

| Чат-бот отвечает | Агент делает |
|---|---|
| Вы спрашиваете — он подсказывает. Всё остальное вы делаете сами. | Вы ставите задачу — он выполняет её до конца и сообщает о результате. |
| Пример: «Как вежливо ответить клиенту?» — получаете текст и отправляете его сами. | Пример: агент сам готовит ответы на новые письма и отправляет их после вашего «да». |

### 3. Задачи, которые можно автоматизировать

**H2:** Что можно поручить агенту
Подзаголовок: Начните с одной задачи, которая отнимает больше всего времени. Остальные можно добавить позже.

| Карточка | Описание |
|---|---|
| Почта и ответы клиентам | Сортирует входящие, готовит черновики ответов на типовые вопросы и напоминает о важных письмах. |
| Календарь и запись | Записывает клиентов в свободные окна, переносит встречи и присылает напоминания вам и клиентам. |
| Отчёты и таблицы | Собирает данные из таблиц, считает итоги и присылает готовый отчёт в удобный вам день. |
| Поиск и сводка новостей | Каждое утро просматривает нужные сайты и присылает короткую сводку самого важного для вашего дела. |
| Документы и договоры | Заполняет договоры и счета по вашим шаблонам, проверяет реквизиты и раскладывает файлы по папкам. |
| Соцсети и контент | Предлагает идеи постов, готовит черновики и публикует их по расписанию после вашего одобрения. |

### 4. Как это работает

**H2:** Как это работает — три шага

1. **Рассказываете о задачах.** На бесплатной консультации разбираем ваш день и выбираем, что отдать агенту в первую очередь.
2. **Настраиваем агента.** Подключаем его к вашей почте, календарю и таблицам, объясняем правила и проверяем на реальных примерах.
3. **Агент работает, вы проверяете.** Агент выполняет задачи каждый день, а важные действия присылает вам на подтверждение.

### 5. До и после

**H2:** Один день: без агента и с агентом
Подзаголовок: Примерный расчёт для обычного рабочего дня предпринимателя. Ваши цифры зависят от задач.

| Задача | Без агента | С агентом |
|---|---|---|
| Разбор почты и ответы | 1 ч | около 20 мин |
| Запись клиентов и переписка | 40 мин | около 10 мин |
| Отчёты и таблицы | 30 мин | около 10 мин |
| Поиск информации | 30 мин | около 10 мин |
| Документы и счета | 30 мин | около 20 мин |
| **Итого за день** | **3 ч 10 мин** | **около 1 ч 10 мин** |

Итог: в среднем около 2 часов в день — это до 10 часов в неделю на клиентов, семью или отдых.

### 6. Безопасность

**H2:** Ваши данные под контролем
Подзаголовок: Агент — помощник, а не замена. Он работает по вашим правилам и не принимает важных решений за вас.

- **Данные остаются в ваших сервисах.** Письма, файлы и таблицы хранятся там же, где и сейчас: в вашей почте, облаке и календаре.
- **Доступ выдаёте вы.** Агент видит только то, к чему вы открыли доступ. Отключить его можно в любой момент.
- **Всё прозрачно.** Каждое действие агента видно в отчёте: что сделано, когда и почему.

Агент делает сам: сортирует письма и готовит черновики ответов; заполняет таблицы и собирает отчёты; присылает напоминания и сводки.

Только после вашего подтверждения: отправляет письма и сообщения клиентам; переносит и отменяет встречи; публикует посты; удаляет письма и файлы. Платежей и переводов денег агент не совершает.

### 7. Вопросы и ответы

**H2:** Частые вопросы

1. **Сколько это стоит?** Стоимость зависит от задач и числа сервисов, которые нужно подключить. На бесплатной консультации разберём ваши задачи и назовём цену до начала работы.
2. **Нужно ли уметь программировать?** Нет. Вы рассказываете о задачах обычными словами, настройку мы берём на себя. Пользоваться агентом можно через привычные почту и мессенджер.
3. **Это сложно в использовании?** Нет. Агент присылает результаты и вопросы туда, где вам удобно, а вы отвечаете «да» или «нет». Никаких новых программ осваивать не нужно.
4. **Какие сервисы можно подключить?** Почту, календари, таблицы, облачные диски, мессенджеры и CRM. Точный список для ваших задач уточним на консультации.
5. **Что, если агент ошибётся?** Важные действия агент выполняет только после вашего подтверждения, а все его шаги видны в отчёте. Правила можно поправить в любой момент.
6. **Чем агент отличается от чат-бота?** Чат-бот отвечает на вопросы, а агент выполняет задачу до конца: пишет, заполняет, записывает и сообщает о результате.
7. **Что будет на бесплатной консультации?** Разберём ваш рабочий день, найдём задачи, которые проще всего отдать агенту, и покажем, как это будет работать.

### Отличия от ТЗ и что важно знать

- **Nginx + Apache.** На тестовом сервере работает Nginx + PHP-FPM, Apache нет. Для Apache добавлен `.htaccess`, для Nginx — готовый конфиг в разделе «Установка».
- **ID Метрики не в коде страницы.** Страница статическая (`index.html`), поэтому номер счётчика она получает из `config.php` через `send.php?action=config` и подключает Метрику скриптом с теми же настройками, что и код из кабинета. Из-за этого нет `<noscript>`-пикселя Метрики — для него ID пришлось бы вписать в HTML; без JavaScript сайт посещают единицы, на статистику это почти не влияет.
- **Превью для соцсетей — PNG.** Соцсети и мессенджеры не показывают SVG в превью, поэтому `og-image.png` (1200×630) отрисован из той же SVG-иллюстрации. Страница его не загружает, на вес и скорость он не влияет.
- **Ссылки на контакты через `data-href`**, пока не заменены плейсхолдеры (см. «Плейсхолдеры»). Так страница валидна уже сейчас.
- **Шрифт Manrope** подключён из Google Fonts без блокировки отрисовки: до загрузки текст показывается системным шрифтом.
- **Форма на тестовом сервере** пока отвечает «сайт ещё не настроен»: `config.php` не создан, потому что нет ни токена бота, ни почты. Успешная отправка проверена локально (PHP 8.1) и в браузере.
